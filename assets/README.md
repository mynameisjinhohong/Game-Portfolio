# assets/

이미지 생성 작업에서 사용하는 프롬프트 초안 및 참조 자료를 보관한다.

## 폴더 구조

```
assets/
├── prompts/     # codex_imagegen 작업용 이미지 생성 프롬프트 텍스트 파일
└── references/  # 스타일 참조 이미지 또는 색상 팔레트 메모
```

## 실제 생성 이미지 저장 위치

생성된 이미지 파일은 Next.js 프로젝트의 `public/images/` 아래에 저장한다.  
경로 규칙은 `docs/planning/art-resource-manifest.md` 참조.
