# 아이디어 우선순위 및 MVP 반영안 정리

> **이 문서의 위치**: GP-3 브레인스토밍에서 도출된 전체 아이디어 12개를 대상으로
> 구현 우선순위를 분류하고 1차 배포 MVP 범위를 확정한다.
> 추가·삭제 없이 GP-3 동일 목록을 기반으로 평가했다.

---

## 📌 챗봇 분류에 대한 범위 조정 사유

프로젝트 컨텍스트는 **'홍진호 소개 챗봇'을 반드시 반영할 기능**으로 명시하고 있다.
이 문서에서 챗봇을 P2(2차 배포)로 분류한 것은 **제품 목표를 낮추는 결정이 아니라**,
아래 이유로 인한 **단계적 출시 전략**이다:

| 조정 사유 | 내용 |
|-----------|------|
| 로컬 LLM 환경 구축 선행 필요 | 맥미니 상시 온 상태 유지, Ollama 등 설치·설정이 배포 전에 완료되어야 함 |
| 운영 안정성 검증 | 서버 부하, 응답 품질, 다운타임 대응은 1차 배포 전 검증이 어려움 |
| 컨텍스트 완성 선행 필요 | 챗봇이 참조할 게임 갤러리·프로젝트 카드 콘텐츠가 먼저 완성되어야 챗봇 품질이 확보됨 |

**결론**: 챗봇은 포트폴리오의 최종 목표에 반드시 포함되며,
1차 정적 콘텐츠 배포 직후 우선 착수하는 기능이다.
MVP 제외는 "만들지 않겠다"가 아니라 "콘텐츠 기반 완성 후 즉시 구현한다"는 의미다.

## 📋 GP-3 아이디어 목록 (평가 대상 전체)

이 문서는 GP-3 브레인스토밍에서 제시된 다음 12개 아이디어를 모두 대상으로 평가한다:

1. 히어로 섹션 (자기소개 + CTA)
2. 게임 갤러리 페이지
3. 프로젝트 상세 카드
4. 기술 스택 시각화
5. 반응형 UI + 다크모드
6. 홍진호 소개 챗봇 (로컬 LLM 기반)
7. 개발 과정 타임라인
8. 게임 인터랙티브 데모 임베드
9. 방문자 플레이 통계 (Itch.io 연동)
10. 블로그/개발 일지
11. 다국어 지원 (영어/한국어)
12. 애니메이션 인트로 화면

---

## 평가 기준

| 기준 | 설명 |
|------|------|
| **임팩트** | 채용 담당자에게 홍진호를 기억에 남기는 효과 |
| **구현 난이도** | 1(쉬움) ~ 5(어려움), 단독 개발자 기준 |
| **채용 메시지 전달력** | 개발자로서의 역량을 직접적으로 증명하는 정도 |
| **참신함** | 일반적인 포트폴리오 대비 차별화 정도 |

## 우선순위 분류

### 🟢 P1 — MVP 필수 포함 (1차 배포 목표)

> **선정 기준**: 방문자가 5분 이내에 "홍진호가 어떤 개발자인지"를 파악할 수 있어야 함.
> 정적 콘텐츠 중심으로 구성해 배포 안정성을 확보한다.

| # | 기능 | 임팩트 | 난이도 | 선정 이유 |
|---|------|--------|--------|-----------|
| 1 | **히어로 섹션** | ★★★★☆ | 1 | 10초 내 "게임 개발자 홍진호" 전달. 짧고 강한 자기소개 문구 + 게임 갤러리 바로가기 CTA. |
| 2 | **게임 갤러리 페이지** | ★★★★★ | 2 | 포트폴리오 핵심 목적. 썸네일·사용 기술·Itch.io 링크를 카드 형식으로 즉시 노출. |
| 3 | **프로젝트 상세 카드** | ★★★★☆ | 2 | 각 게임에서 맡은 역할, 사용 기술, 배운 점, 개발 기간을 구체적으로 기술. |
| 4 | **기술 스택 시각화** | ★★★★☆ | 2 | 텍스트 나열 대신 아이콘/바 차트 형식으로 역량 직관적 전달. |
| 5 | **반응형 UI + 다크모드** | ★★★☆☆ | 2 | 모바일 방문자 경험 보장 및 기술적 완성도 신호. MVP 단계에서 기본 구현. |

---

### 🟡 P2 — 2차 배포 권장 (1차 배포 직후 착수)

> **선정 기준**: 임팩트는 높지만 구현/운영 비용이 크거나, 1차 정적 콘텐츠 완성 후 추가해야 효과가 극대화되는 요소.
> 챗봇은 필수 기능이나 LLM 운영 환경과 콘텐츠 기반이 먼저 갖춰져야 품질이 보장되므로 단계적 출시로 조정한다 (상단 범위 조정 사유 참고).

| # | 기능 | 임팩트 | 난이도 | 선정 이유 |
|---|------|--------|--------|-----------|
| 6 | **홍진호 소개 챗봇** | ★★★★★ | 4 | 포트폴리오 필수 기능. 맥미니 로컬 LLM 환경 구축 및 게임 갤러리 콘텐츠 완성 후 즉시 구현. 운영 안정성 확보가 선행 조건. |
| 7 | **개발 과정 타임라인** | ★★★★☆ | 3 | 기획→개발→출시 흐름 시각화로 프로세스 이해력 증명. 콘텐츠 작성 시간 별도 필요. |
| 8 | **게임 인터랙티브 데모 임베드** | ★★★★★ | 4 | WebGL 빌드를 브라우저에서 직접 플레이 가능 시 강렬한 인상. 로딩 성능 최적화 선행 필요. |
| 9 | **방문자 플레이 통계 (Itch.io 연동)** | ★★★☆☆ | 3 | 실제 플레이어 데이터 노출로 신뢰도 상승. API 연동 별도 구현 필요. |

---

### 🔴 P3 — 추후 검토

> **선정 기준**: 콘텐츠 유지 비용이 높거나, 현재 채용 목표와 맞지 않거나, 잘못 구현 시 UX를 해치는 요소.

| # | 기능 | 임팩트 | 난이도 | 선정 이유 |
|---|------|--------|--------|-----------|
| 10 | **블로그/개발 일지** | ★★★☆☆ | 3 | 꾸준함 증명에 유효하나 콘텐츠 유지 비용 높음. 초기엔 선택적. |
| 11 | **다국어 지원 (영어/한국어)** | ★★★☆☆ | 3 | 해외 채용 목표 시 유효. 현재 국내 취업 우선이면 보류. |
| 12 | **애니메이션 인트로 화면** | ★★☆☆☆ | 3 | 참신하지만 스킵 기능 없으면 UX 방해. 1차에서는 제외. |

## MVP 후보 기능 (1차 버전 확정 범위)

> **기준**: 단독 개발자, 2~3주 내 완성 가능, 정적 콘텐츠 중심, 배포 안정성 확보.

### ✅ MVP 포함

| 기능 | 목표 |
|------|------|
| 히어로 섹션 | "게임 개발자 홍진호" 한 줄 소개 + 주요 링크 |
| 게임 갤러리 | 썸네일, 제목, 사용 기술, Itch.io 링크, 한 줄 설명 |
| 프로젝트 상세 카드 | 역할, 사용 기술, 배운 점, 개발 기간 |
| 기술 스택 섹션 | 아이콘 기반 시각화 |
| 반응형 UI + 다크모드 | 기본 수준 구현 |

### ⏳ 1차 배포 직후 착수 (필수 기능, 단계적 출시)

| 기능 | 착수 조건 |
|------|-----------|
| 홍진호 소개 챗봇 | 1차 배포 완료 후 즉시. 맥미니 로컬 LLM 환경 구축 + 게임 콘텐츠 기반 컨텍스트 완성이 선행 조건 |

### ❌ MVP 제외 (P2/P3 추후 반영)

| 기능 | 제외 이유 |
|------|-----------|
| 인터랙티브 게임 데모 | WebGL 로딩 성능 이슈 사전 검토 필요 |
| 개발 타임라인 | 콘텐츠 작성 시간 별도 필요 |
| 블로그/개발 일지 | 유지 비용 대비 초기 우선순위 낮음 |
| 다국어 지원 | 현재 채용 목표 범위 외 |
| 애니메이션 인트로 | UX 방해 가능성 |

## 우선순위 선정 요약

**P1 기준**: 방문자가 5분 이내에 홍진호의 결과물과 역량을 명확히 파악할 수 있어야 함.
정적 콘텐츠(갤러리, 기술 스택, 프로젝트 카드)로 배포 안정성을 먼저 확보한다.

**P2 기준**: 임팩트는 크지만 구현·운영 비용이 높아 1차 정적 콘텐츠 완성 후 즉시 착수해야 하는 기능.
챗봇은 포트폴리오 필수 기능이며 "운영 가능한 LLM 환경 + 콘텐츠 기반 확보 후" 단계적 출시로 조정한다.

**P3 기준**: 콘텐츠 유지 비용이 높거나, 현재 채용 목표와 맞지 않거나,
잘못 구현 시 UX를 오히려 해치는 요소들.
