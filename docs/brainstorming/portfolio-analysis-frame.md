# 포트폴리오 분석 기준과 인물 표현 프레임

## 1. 홍진호를 어떤 개발자로 인식시킬 것인가

### 핵심 포지셔닝 메시지
> "직접 만든 게임과 대화형 AI 챗봇으로 자신을 소개하는, 실행력과 기술 탐구력을 동시에 가진 개발자"

**포지셔닝 근거 (리뷰 반영)**:
단순히 "게임을 만들고 배포한 개발자"라는 메시지는 첫인상으로서 차별성이 부족하다. 대신 **AI 챗봇을 전면에 배치**하여, 방문자가 사이트에 들어오자마자 홍진호와 직접 대화할 수 있는 경험을 제공한다. 챗봇이 단순 장식이 아니라 포트폴리오 탐색의 진입점 역할을 하면, 인사담당자에게 "이 개발자는 다르다"는 인상을 즉시 줄 수 있다.

### 인물 표현 프레임
- **정체성**: 게임 개발자 + AI 도구를 직접 구현하는 소프트웨어 엔지니어
- **강점 키워드**: 실행력, 완성도, 사용자 관점, 자기주도, 기술 응용력
- **차별점**: 아이디어를 Itch.io 배포까지 완성한 경험 + 포트폴리오 자체에 AI 챗봇을 내장

## 2. 분석 대상 정보 항목

포트폴리오 웹이 전달해야 할 정보를 구성하기 위해 노션 포트폴리오에서 추출해야 할 항목:

| 항목 | 설명 |
|------|------|
| 자기소개 | 한 줄 소개, 개발자 정체성 |
| 게임 프로젝트 목록 | 제목, 장르, 개발 기간, 플랫폼 |
| 각 게임의 역할 | 단독 개발 / 팀 내 역할 분담 |
| 사용 기술 스택 | 엔진(Unity 등), 언어, 도구 |
| 배포 링크 | Itch.io 등 실제 플레이 가능 URL |
| 프로젝트별 배운 점 | 기술적·비기술적 인사이트 |
| 경력 및 학력 | 직무 경험, 수료 과정 |
| 기술 역량 | 언어, 프레임워크, 도구 목록 |
| 개인 링크 | GitHub, 블로그, 연락처 |
| 챗봇 학습 소재 | 위 항목 전체를 챗봇 컨텍스트로도 활용 |

## 3. 핵심 사용자 3종별 기대 행동 및 관심사

### 3-1. 면접관 (기술 검증 목적)
- **기대 행동**: 기술 스택과 코드 품질 확인, GitHub 방문
- **관심사**: 사용 기술의 깊이, 문제 해결 경험, 협업 능력
- **필요 정보**: 프로젝트별 기술 상세, 트러블슈팅 경험, 코드 링크
- **챗봇 활용**: "이 게임에서 가장 어려웠던 기술적 문제는?" 같은 질문을 챗봇에 바로 물어볼 수 있다

### 3-2. 인사담당자 (인상 형성 목적)
- **기대 행동**: 30초 내 이 사람이 무엇을 만들었는지 파악
- **관심사**: 완성된 결과물의 수, 성장 스토리, 커뮤니케이션 능력
- **필요 정보**: 완성 게임 목록, 짧고 명확한 소개, 시각적 결과물(스크린샷/GIF)
- **챗봇 활용**: 챗봇이 첫 화면에 있으면 "어떤 개발자예요?" 한 마디로 핵심을 파악 가능 → 가장 높은 차별성 제공

### 3-3. 첫 방문 실무자 (탐색 목적)
- **기대 행동**: 흥미로운 게임을 클릭해 직접 플레이 또는 영상 시청
- **관심사**: 게임의 재미와 완성도, 개발자의 개성
- **필요 정보**: 게임 플레이 링크, 핵심 특징 요약, 개발 비하인드
- **챗봇 활용**: "어떤 게임부터 해볼까요?" 같은 탐색 질문에 답변 가능

## 4. 기능 아이디어 평가 기준

이후 브레인스토밍에서 도출된 기능 아이디어를 아래 기준으로 평가한다:

### 기준 1. 핵심 메시지 전달력
- 이 기능이 "실행력과 기술 탐구력을 겸비한 개발자"라는 인물 프레임을 강화하는가?
- 방문자가 홍진호를 더 잘 기억하게 만드는가?

### 기준 2. 핵심 사용자 도달 효율
- 면접관·인사담당자·첫 방문자 중 적어도 2종 이상에게 직접적으로 가치를 제공하는가?
- 30초 내 주요 가치가 전달되는가?

### 기준 3. 구현 대비 임팩트
- 개발 복잡도 대비 사용자 경험 개선 효과가 큰가?
- MVP 수준에서 동작 가능한가, 아니면 완성도 있는 구현이 필수인가?

### 기준 4. 결과물 중심성
- 설명보다 실제 게임/데모 또는 인터랙션이 먼저 눈에 들어오는 구성을 지원하는가?
- 텍스트보다 시각·인터랙션으로 경험을 전달하는가?

### 기준 5. 참신함과 단순함의 균형
- 면접관이 "이건 다르다"고 느낄 만한 요소가 있는가?
- 동시에 처음 방문자도 직관적으로 탐색 가능한가?

## 5. 포트폴리오 웹의 핵심 전달 목표 요약

1. **첫 5초**: 챗봇 인터페이스가 전면에 등장 — "저는 홍진호입니다. 무엇이 궁금하세요?" 로 시작
2. **첫 30초**: 챗봇을 통해 또는 스크롤을 통해 대표 게임 1~2개의 비주얼과 플레이 링크 확인
3. **1~3분**: 기술 스택, 역할, 배운 점을 통해 개발자 역량 검증 가능
4. **3분+**: 챗봇 심층 질의 또는 상세 프로젝트 페이지로 탐색 계속
