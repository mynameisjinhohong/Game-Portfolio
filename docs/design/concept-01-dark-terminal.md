# 컨셉 01 — 다크 터미널 (Dark Terminal)

**이미지:** `docs/design/images/concept-01-dark-terminal.png`

---

## 제작 의도

개발자 정체성을 직관적으로 전달하기 위해 CLI 터미널 미학을 채택했습니다.  
방문자가 "이 사람은 기술적으로 깊이 있다"는 인상을 첫눈에 받도록 설계했으며,  
녹색 텍스트(#00FF41) + 검정 배경의 고대비 조합으로 시각적 강렬함을 극대화했습니다.  
타이핑 애니메이션과 커서 깜빡임을 통해 방문자가 실제 터미널에 접속하는 느낌을 부여합니다.

---

## 강점

- **즉각적인 신뢰감:** 개발자·채용 담당자에게 기술적 깊이를 첫 화면에서 전달
- **강렬한 첫인상:** 녹색/검정 조합은 기억 각인 효과가 높음
- **복합 역량 암시:** 게임 개발 + 시스템 이해도를 동시에 드러냄
- **챗봇 통합 자연스러움:** 터미널 AI로 챗봇을 녹이면 UI 일관성 완성

---

## 약점

- **냉담한 첫인상:** 비기술직 채용 담당자에게는 낯설고 차가운 느낌을 줄 수 있음
- **접근성 이슈:** 녹색-검정 고대비 조합은 일부 시각 장애 사용자에게 부담
- **클리셰 위험:** 해커 영화 이미지와 겹쳐 진부하게 읽힐 가능성
- **콘텐츠 레이아웃 제약:** 이미지·GIF를 풍부하게 보여주기 어려운 구조

---

## 적합 맥락

- 프로그래밍 중심 역할(백엔드·시스템 프로그래밍) 지원 시
- 기술적 문화를 중시하는 인디·AA 게임 스튜디오 지원 시
- 챗봇을 "터미널 AI 어시스턴트"로 연출하고 싶을 때
