# 컨셉 02 — 픽셀 아트 레트로 (Pixel Art Retro)

**이미지:** `docs/design/images/concept-02-pixel-retro.png`

---

## 제작 의도

인디 게임 개발자의 감성을 시각 언어 자체로 전달하는 컨셉입니다.  
8비트·16비트 픽셀 아트 스타일을 채택해 포트폴리오 자체가 하나의 게임처럼 느껴지도록 설계했습니다.  
방문자가 사이트를 여는 순간 "이 사람은 게임을 만든다"는 사실이 설명 없이 전달됩니다.

---

## 강점

- **정체성 즉시 명확화:** 게임 개발자라는 사실이 첫 화면에서 시각적으로 증명됨
- **포트폴리오 = 게임 체험:** 방문 자체가 하나의 미니 게임 경험이 될 수 있음
- **기억 각인 효과 최강:** 픽셀 스타일은 독특해서 방문자 기억에 오래 남음
- **챗봇 캐릭터 통합:** 픽셀 아트 NPC 캐릭터로 챗봇을 표현하면 시너지 극대화

---

## 약점

- **대기업 HR 거부감:** "장난스럽다"는 인식 가능 — 진지성이 요구되는 지원처에 불리
- **모바일 선명도 문제:** 픽셀 렌더링 시 화면 배율에 따라 흐릿하게 보일 수 있음
- **구현 복잡도:** 픽셀 아트 에셋 제작 + 웹 렌더링 모두 시간 소요
- **콘텐츠 가독성 제한:** 픽셀 폰트는 긴 텍스트 가독성이 낮음

---

## 적합 맥락

- 인디 게임 스튜디오, 창의적 문화를 강조하는 팀 지원 시
- 게임 잼·개인 프로젝트 비중이 높을 때
- 구현 시간이 충분하고 아트 에셋 제작 역량이 있을 때
