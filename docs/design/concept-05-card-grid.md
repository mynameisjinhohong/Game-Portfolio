# 컨셉 05 — 카드 그리드 갤러리 (Card Grid Gallery)

**이미지:** `docs/design/images/concept-05-card-grid.png`

---

## 제작 의도

프로젝트를 카드 형태로 그리드 배치해 한 화면에서 최대한 많은 작업물을 보여주는 구조입니다.  
빠른 시각적 스캔을 위한 레이아웃으로, 채용 담당자가 짧은 시간에 전체 프로젝트 규모를 파악할 수 있도록 설계했습니다.  
호버 효과로 각 카드의 추가 정보(기술 스택, 역할, 링크)가 드러나는 인터랙션을 포함합니다.

---

## 강점

- **정보 밀도:** 여러 프로젝트를 한 화면에서 빠르게 파악 가능
- **반응형 구현 용이:** CSS Grid/Flexbox 기반으로 구조가 단순
- **필터·정렬 확장성:** 장르, 기술 스택 등으로 필터링 기능을 붙이기 쉬움
- **친숙한 패턴:** 포트폴리오 방문 경험이 있는 사람에게 즉시 이해 가능

---

## 약점

- **개별 임팩트 희석:** 카드 하나하나의 존재감이 약해짐
- **카드 수 의존성:** 프로젝트가 적으면(3개 이하) 레이아웃이 어색해 보임
- **차별성 부족:** 수많은 개발자 포트폴리오가 이미 동일한 구조를 사용
- **깊이 있는 프로젝트 설명 어려움:** 카드 포맷의 특성상 내용이 압축됨

---

## 적합 맥락

- 프로젝트 수가 많고(6개 이상) 빠른 탐색이 중요한 경우
- 다양한 장르·기술의 프로젝트를 분류해 보여주고 싶을 때
- 빠른 프로토타이핑이 필요한 MVP 버전으로 적합
