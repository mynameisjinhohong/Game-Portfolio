# 컨셉 06 — 인터랙티브 맵 (Interactive Map)

**이미지:** `docs/design/images/concept-06-interactive-map.png`

---

## 제작 의도

포트폴리오를 탐험할 수 있는 게임 월드맵 형태로 설계한 컨셉입니다.  
방문자가 지도 위의 각 지역(= 프로젝트)을 직접 클릭하거나 이동하며 탐색하도록 유도해,  
포트폴리오 열람 자체가 하나의 게임 경험이 되도록 기획했습니다.  
RPG 월드맵의 구역 이동, 포인트 오브 인터레스트 등의 메카닉을 차용했습니다.

---

## 강점

- **게임 감성 완전 통합:** 포트폴리오와 게임 메카닉이 한 몸이 됨
- **참여도·기억 각인 최상위:** 능동적 탐색은 수동적 스크롤보다 훨씬 강한 인상을 남김
- **챗봇 시너지:** 맵 탐색 중 가이드 NPC 역할로 챗봇을 자연스럽게 통합 가능
- **독창성 최상:** 이 형태의 포트폴리오는 매우 드물어 강력한 차별화 무기

---

## 약점

- **구현 난이도 최고:** Canvas API 또는 게임 엔진 수준의 인터랙션 구현 필요
- **모바일 처리 복잡:** 터치 기반 맵 탐색 UX 설계가 별도로 필요
- **직관성 우려:** 게임 맥락에 익숙하지 않은 방문자에게 진입 장벽이 될 수 있음
- **로딩 성능:** 맵 에셋이 무거우면 초기 로딩 지연

---

## 적합 맥락

- 게임 메카닉 이해도와 프런트엔드 구현 역량을 동시에 증명하고 싶을 때
- 충분한 구현 시간(2주 이상)이 확보된 경우
- RPG 또는 어드벤처 장르 게임 제작 경험을 강조하고 싶을 때

---
