# 컨셉 07 — 스플릿 스크린 (Split Screen)

**이미지:** `docs/design/images/concept-07-split-screen.png`

---

## 제작 의도

화면을 두 영역으로 분리해 왼쪽에 게임 비주얼/데모, 오른쪽에 텍스트 정보를 배치한 컨셉입니다.  
방문자가 시각 요소와 정보를 동시에 소화할 수 있도록 설계했으며,  
게임 UI에서 흔히 보이는 "인게임 정보 패널 + 게임 화면" 구조에서 착안했습니다.

---

## 강점

- **콘텐츠·비주얼 균형:** 이미지와 텍스트가 자연스럽게 공존
- **게임 UI 친숙함:** 게임 업계 종사자에게 직관적으로 읽히는 레이아웃
- **스크롤 없이 핵심 전달:** 좌우 각 섹션에서 핵심 정보를 한눈에 파악 가능
- **구현 복잡도 중간:** CSS Flexbox/Grid로 기본 레이아웃 구성 가능

---

## 약점

- **좁은 화면 레이아웃 붕괴:** 태블릿 이하 해상도에서 좌우 분리가 무너짐
- **텍스트 영역 제한:** 오른쪽 패널에 담을 수 있는 정보량이 제한적
- **좌우 분리감:** 두 영역의 시각적 연결이 어색하게 느껴질 수 있음
- **모바일 재설계 필요:** 세로 화면에서는 별도의 레이아웃 전환 전략 필요

---

## 적합 맥락

- 데스크탑 우선 방문자가 많을 때
- 게임 플레이 영상·GIF를 전면 배치하고 싶을 때
- 프로젝트당 한 페이지씩 깊게 소개하는 구조에 적합
