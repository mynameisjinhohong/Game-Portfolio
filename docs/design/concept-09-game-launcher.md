# 컨셉 09 — 게임 런처 UI (Game Launcher UI)

**이미지:** `docs/design/images/concept-09-game-launcher.png`

---

## 제작 의도

Steam·Epic Games 런처 UI를 모방해 포트폴리오를 게임 라이브러리처럼 표현한 컨셉입니다.  
방문자가 "게임을 선택하는" 경험을 통해 각 프로젝트를 "플레이 가능한 타이틀"처럼 인식하도록 유도합니다.  
왼쪽 게임 목록 패널, 오른쪽 선택된 게임 상세 패널 구조를 채택해 익숙한 UX를 활용합니다.

---

## 강점

- **게임 업계 공감:** 게임 업계 종사자에게 즉각적인 친숙함과 공감 유발
- **프로젝트 포지셔닝:** 각 게임을 "출시 타이틀"처럼 포지셔닝해 가치 상승
- **학습 곡선 없음:** 익숙한 UI 패턴으로 별도 설명 없이 탐색 가능
- **정보 구조 명확:** 목록-상세 패턴이 정보 계층을 자연스럽게 구분

---

## 약점

- **독창성 부족:** Steam 런처를 너무 직접적으로 차용해 "따라한 것" 인상 가능
- **게임 업계 외 방문자:** 런처 UI에 익숙하지 않은 HR에게는 낯선 인터페이스
- **완성도 압박:** 실제 런처와 비교될 수 있어 디테일 구현 수준이 높아야 함
- **모바일 레이아웃:** 목록-상세 패턴은 좁은 화면에서 별도 처리 필요

---

## 적합 맥락

- 게임 회사 취업에 특화된 포트폴리오가 필요할 때
- 게임 경험자·게임 마니아 대상 지원처
- 인터랙티브 맵(컨셉 06) 대비 구현 시간을 줄이면서도 게임 감성을 살리고 싶을 때
