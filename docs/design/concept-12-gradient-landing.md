# 컨셉 12 — 그라데이션 랜딩 (Gradient Landing)

**이미지:** `docs/design/images/concept-12-gradient-landing.png`

---

## 제작 의도

풍부한 그라데이션 배경과 카드 기반 레이아웃을 결합한 컨셉입니다.  
시각적으로 따뜻하고 접근하기 쉬운 첫인상을 목표로 설계했으며,  
그라데이션 자체가 별도의 설명 없이 시각적 관심을 자연스럽게 유도하는 역할을 합니다.

---

## 강점

- **접근성 높음:** 친근하고 현대적인 느낌으로 거부감이 없음
- **자연스러운 시선 유도:** 그라데이션 방향이 시선 흐름을 안내
- **빠른 프로토타이핑:** 구현 난이도가 가장 낮아 MVP 제작에 적합
- **배경 수정 용이:** CSS 그라데이션만 변경해도 전혀 다른 분위기를 연출 가능

---

## 약점

- **싸구려 인상 위험:** 과도하거나 잘못된 그라데이션은 저품질 느낌을 줄 수 있음
- **독창성 부족:** 최근 수많은 포트폴리오·랜딩 페이지가 동일 트렌드를 사용
- **게임 포트폴리오 정체성 약함:** 일반 웹 서비스와 구분되는 게임 개발자 감성이 없음
- **장기 유지보수:** 유행하는 그라데이션 스타일은 빠르게 촌스럽게 느껴질 수 있음

---

## 적합 맥락

- 디자인에 많은 시간을 투자할 수 없을 때의 기본 출발점
- 기능 중심 포트폴리오(챗봇, 필터링 등)를 빠르게 출시하고 디자인은 나중에 개선하는 접근법
- 첫 MVP 버전으로 빠르게 배포해야 할 때
