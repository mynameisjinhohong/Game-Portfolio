## 시안 목록 및 분석

### 컨셉 1 — 다크 터미널 (Dark Terminal)

**이미지:** `docs/design/images/concept-01-dark-terminal.png`

**제작 의도**  
개발자 정체성을 직관적으로 전달하기 위해 CLI 터미널 미학을 채택. 방문자가 "이 사람은 기술적으로 깊이 있다"는 인상을 첫눈에 받도록 설계.

**강점**
- 개발자·채용 담당자에게 즉각적인 신뢰감 형성
- 녹색 텍스트 / 검정 배경 조합으로 강렬한 첫인상
- 게임 개발 + 시스템 이해도를 동시에 암시

**약점**
- 비기술직 채용 담당자에게는 낯설고 차가운 느낌
- 접근성(가독성) 이슈 — 고대비 모드 필요
- 지나치게 클리셰적으로 읽힐 위험

**적합 맥락:** 프로그래밍 중심 역할 지원, 인디/AA 게임 스튜디오 지원

---

### 컨셉 2 — 픽셀 아트 레트로 (Pixel Art Retro)

**이미지:** `docs/design/images/concept-02-pixel-retro.png`

**제작 의도**  
인디 게임 개발자의 감성을 전달. 8비트·16비트 픽셀 아트 스타일로 게임 제작 경험을 시각 언어 자체로 보여줌.

**강점**
- 게임 개발자라는 정체성이 즉시 명확해짐
- 포트폴리오 자체가 하나의 게임처럼 느껴지는 경험
- 독특한 기억 각인 효과가 강함

**약점**
- 대기업 HR 담당자에게는 "장난스럽다"는 인식 가능
- 픽셀 렌더링에 따른 모바일 선명도 문제
- 구현 복잡도가 상대적으로 높음

**적합 맥락:** 인디 게임 스튜디오, 창의적 문화를 강조하는 팀 지원

---

### 컨셉 3 — 미니멀 화이트 (Minimal White)

**이미지:** `docs/design/images/concept-03-minimal-white.png`

**제작 의도**  
콘텐츠 자체에 집중시키는 디자인. 불필요한 장식 제거, 게임 스크린샷과 텍스트가 주인공이 되도록 설계.

**강점**
- 전문성·성숙함 전달에 효과적
- 빠른 로딩 및 높은 접근성
- 어떤 직군의 채용 담당자에게도 거부감 없음

**약점**
- 기억에 남는 차별성이 낮음
- "평범하다"는 인상을 줄 수 있음
- 게임 포트폴리오의 역동성이 억제됨

**적합 맥락:** 대기업, 퍼블리셔, 전문성을 강조해야 하는 지원

---

### 컨셉 4 — 네온 사이버펑크 (Neon Cyberpunk)

**이미지:** `docs/design/images/concept-04-neon-cyberpunk.png`

**제작 의도**  
SF·사이버펑크 장르 감성으로 게임 포트폴리오에 어울리는 미래지향적 분위기 조성. 보라·파랑·분홍 네온 팔레트 활용.

**강점**
- 시각적 임팩트가 매우 강함
- 트렌디한 게임 업계 감성과 일치
- 방문자 체류 시간 증가 기대

**약점**
- 화려함이 콘텐츠를 가릴 위험
- 과도한 애니메이션은 집중력 분산
- 일부 사용자에게 눈의 피로 유발 가능

**적합 맥락:** 아트 드리븐 스튜디오, 비주얼 임팩트를 중시하는 게임 회사

---

### 컨셉 5 — 카드 그리드 갤러리 (Card Grid Gallery)

**이미지:** `docs/design/images/concept-05-card-grid.png`

**제작 의도**  
프로젝트를 카드 형태로 그리드 배치해 한 화면에서 최대한 많은 작업물을 보여주는 구조. 빠른 스캔을 위한 레이아웃.

**강점**
- 정보 밀도가 높아 여러 프로젝트를 빠르게 파악 가능
- 반응형 구현이 상대적으로 용이
- 필터·정렬 기능과 결합 시 시너지 높음

**약점**
- 각 프로젝트의 개별 임팩트가 약해질 수 있음
- 카드 수가 적으면 레이아웃이 어색해 보임
- 다른 포트폴리오와 차별성이 낮음

**적합 맥락:** 프로젝트 수가 많고(6개 이상) 빠른 탐색이 중요한 경우

---

### 컨셉 6 — 인터랙티브 맵 (Interactive Map)

**이미지:** `docs/design/images/concept-06-interactive-map.png`

**제작 의도**  
포트폴리오를 탐험할 수 있는 지도 형태로 설계. 게임의 월드맵 개념을 차용해 방문자가 능동적으로 탐색하도록 유도.

**강점**
- 게임 감성과 포트폴리오가 완벽히 통합
- 방문자 참여도·기억 각인 효과 최상위
- 챗봇 캐릭터와 결합 시 내러티브 완성도 높음

**약점**
- 구현 난이도가 시안 중 가장 높음
- 모바일에서의 인터랙션 처리 복잡
- 일부 방문자는 직관성이 낮다고 느낄 수 있음

**적합 맥락:** 게임 메카닉 이해도를 보여주고 싶을 때, 충분한 구현 시간이 확보된 경우

---

### 컨셉 7 — 스플릿 스크린 (Split Screen)

**이미지:** `docs/design/images/concept-07-split-screen.png`

**제작 의도**  
화면을 두 영역으로 나눠 왼쪽에 비주얼/게임 데모, 오른쪽에 텍스트 정보를 배치. 시각과 정보를 동시에 소화하도록 설계.

**강점**
- 콘텐츠와 시각 요소의 균형이 좋음
- 게임 UI에서 흔히 보이는 레이아웃으로 친숙함
- 스크롤 없이 핵심 정보 전달 가능

**약점**
- 좁은 화면(태블릿 이하)에서 레이아웃 붕괴 가능
- 텍스트 영역이 작아 정보량 제한
- 좌우 분리감이 어색할 수 있음

**적합 맥락:** 데스크탑 우선 방문자가 많을 때, 게임 영상·GIF를 전면 배치하고 싶을 때

---

### 컨셉 8 — 스토리텔링 스크롤 (Storytelling Scroll)

**이미지:** `docs/design/images/concept-08-storytelling-scroll.png`

**제작 의도**  
스크롤에 따라 홍진호의 개발 여정이 시간 순으로 펼쳐지는 내러티브 구조. 방문자를 "이야기"로 끌어당기는 방식.

**강점**
- 감정적 연결을 만드는 데 효과적
- 스크롤 기반 애니메이션으로 몰입감 형성
- 단순한 이력서와 차별화

**약점**
- 빠른 스캔을 원하는 방문자에게는 답답할 수 있음
- 구현 시 스크롤 퍼포먼스 최적화 필요
- 정보 탐색이 선형적으로 제한됨

**적합 맥락:** 개인 브랜딩이 중요한 경우, 스토리를 강조해야 하는 지원

---

### 컨셉 9 — 게임 런처 UI (Game Launcher UI)

**이미지:** `docs/design/images/concept-09-game-launcher.png`

**제작 의도**  
Steam·Epic Games 런처 UI를 모방해 포트폴리오를 게임 라이브러리처럼 표현. 방문자가 "게임을 선택하는" 경험을 유도.

**강점**
- 게임 업계 종사자에게 즉각적인 공감 유발
- 각 프로젝트를 "플레이 가능한 타이틀"처럼 포지셔닝
- 익숙한 UI 패턴으로 학습 곡선 없음

**약점**
- 기존 런처 UI를 너무 직접적으로 차용해 독창성 부족 우려
- 게임 업계 외 방문자에게는 낯선 인터페이스
- 실제 게임 런처와 비교될 수 있어 완성도 요구 수준이 높음

**적합 맥락:** 게임 회사 취업 특화 포트폴리오, 게임 경험자 대상

---

### 컨셉 10 — 다크 모던 (Dark Modern)

**이미지:** `docs/design/images/concept-10-dark-modern.png`

**제작 의도**  
다크 모드 기반의 현대적 UI 디자인. 적절한 여백, 타이포그래피 위계, 미묘한 글래스모피즘 효과를 결합해 고급스러운 인상을 만듦.

**강점**
- 전문성과 미적 감각을 동시에 전달
- 다크 모드 선호 개발자층에게 높은 호감도
- 적당한 개성 + 높은 가독성의 균형

**약점**
- "흔한 다크 테마 포트폴리오" 군에 묻힐 수 있음
- 차별화 요소를 별도로 추가해야 함

**적합 맥락:** 범용 지원, 기술력과 미적 감각을 둘 다 보여주고 싶을 때

---

### 컨셉 11 — HUD 오버레이 (HUD Overlay)

**이미지:** `docs/design/images/concept-11-hud-overlay.png`

**제작 의도**  
FPS·RPG 게임의 HUD(헤드업 디스플레이) 요소를 포트폴리오에 오버레이. 스킬 바, 퀘스트 로그, 미니맵 형식으로 정보를 표현.

**강점**
- 게임 개발 역량을 디자인으로 직접 증명
- 강렬한 독창성 — 기억에 남을 확률 최상위
- 챗봇을 "NPC 대화창"으로 통합 시 시너지 극대화

**약점**
- 게임 맥락을 모르는 방문자에게 혼란 유발 가능
- 정보 계층 설계가 복잡하고 구현 난이도 높음
- 유희성이 과해지면 진지성이 약해질 위험

**적합 맥락:** 강렬한 인상이 필요한 경우, 게임 엔진/UI 개발 역량을 어필하고 싶을 때

---

### 컨셉 12 — 그라데이션 랜딩 (Gradient Landing)

**이미지:** `docs/design/images/concept-12-gradient-landing.png`

**제작 의도**  
풍부한 그라데이션 배경과 카드 기반 레이아웃 결합. 시각적으로 따뜻하고 접근하기 쉬운 첫인상을 목표로 설계.

**강점**
- 친근하고 현대적인 느낌으로 거부감 없음
- 그라데이션 자체가 시각적 관심을 자연스럽게 유도
- 구현 난이도 낮음 — 빠른 프로토타이핑 가능

**약점**
- 과도한 그라데이션은 싸구려 인상을 줄 수 있음
- 개성 있는 독창성이 부족
- 최근 많은 포트폴리오에서 사용되어 차별성이 낮음

**적합 맥락:** 디자인에 많은 시간을 투자할 수 없을 때의 기본 출발점

## 추천 후보

### 1순위 추천: 컨셉 11 — HUD 오버레이 (+ 컨셉 02 픽셀 아트 혼합)

게임 개발자로서의 정체성을 가장 강력하게 전달하며, 챗봇을 "NPC 대화창"으로 통합하면 포트폴리오 전체가 하나의 게임 경험이 된다. 구현 난이도는 높지만, 완성도가 높을 경우 가장 강한 인상을 남길 수 있다.

**핵심 아이디어:** 상단에 HUD 요소(HP바 → 프로젝트 진행도, 퀘스트 로그 → 커리어 타임라인), 게임 선택 화면에서 프로젝트 탐색, 챗봇은 NPC 대화창.

### 2순위 추천: 컨셉 09 — 게임 런처 UI

범용성과 게임 업계 특화 사이의 균형점. Steam 런처 감성은 채용 담당자에게 익숙하면서도 게임 개발자다움을 자연스럽게 전달한다.

### 빠른 구현이 필요한 경우: 컨셉 10 — 다크 모던 기반 + 컨셉 02 픽셀 아트 액센트

기반 레이아웃은 다크 모던으로 빠르게 구성하고, 게임 개성은 픽셀 아트 요소를 액센트로 추가하는 하이브리드 접근.

## 공통적으로 보이는 방향성

1. **다크 테마 선호** — 12개 중 7개 시안이 어두운 배경을 채택. 게임 개발자 포트폴리오에서 다크 테마는 사실상 표준.
2. **게임 UI 메타포 활용** — 단순히 "게임을 만들었다"고 말하는 것보다, 포트폴리오 자체가 게임처럼 동작하면 더 설득력 있음.
