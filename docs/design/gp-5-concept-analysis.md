## 추천 후보

### 1순위 추천: 컨셉 11 — HUD 오버레이 (+ 컨셉 02 픽셀 아트 혼합)

게임 개발자로서의 정체성을 가장 강력하게 전달하며, 챗봇을 "NPC 대화창"으로 통합하면 포트폴리오 전체가 하나의 게임 경험이 된다. 구현 난이도는 높지만, 완성도가 높을 경우 가장 강한 인상을 남길 수 있다.

**핵심 아이디어:** 상단에 HUD 요소(HP바 → 프로젝트 진행도, 퀘스트 로그 → 커리어 타임라인), 게임 선택 화면에서 프로젝트 탐색, 챗봇은 NPC 대화창.

### 2순위 추천: 컨셉 09 — 게임 런처 UI

범용성과 게임 업계 특화 사이의 균형점. Steam 런처 감성은 채용 담당자에게 익숙하면서도 게임 개발자다움을 자연스럽게 전달한다.

### 빠른 구현이 필요한 경우: 컨셉 10 — 다크 모던 기반 + 컨셉 02 픽셀 아트 액센트

기반 레이아웃은 다크 모던으로 빠르게 구성하고, 게임 개성은 픽셀 아트 요소를 액센트로 추가하는 하이브리드 접근.

## 공통적으로 보이는 방향성

1. **다크 테마 선호** — 12개 중 7개 시안이 어두운 배경을 채택. 게임 개발자 포트폴리오에서 다크 테마는 사실상 표준.
2. **게임 UI 메타포 활용** — 단순히 "게임을 만들었다"고 말하는 것보다, 포트폴리오 자체가 게임처럼 동작하면 더 설득력 있음.
3. **챗봇과의 시너지** — 챗봇을 NPC, 가이드 캐릭터, 터미널 AI로 통합하면 전체 경험이 일관되게 연결됨.
4. **프로젝트 결과물 우선** — 텍스트 중심 이력서가 아닌, 게임 스크린샷·GIF·링크가 주인공이 되는 레이아웃을 공통으로 지향.
