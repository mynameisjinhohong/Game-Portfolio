# 전체 실행 로드맵 및 우선순위 백로그

**작성일:** 2026-05-10  
**기반 문서:** GP-4(MVP 우선순위), GP-5(디자인 컨셉 분석), GP-3(기능 아이디어)  
**목적:** 포트폴리오 사이트 전체 개발 순서를 단계별로 정리하고, 각 작업의 선행 조건 및 병렬 진행 가능 여부를 명시한다.

---

## 단계 개요

| 단계 | 명칭 | 목표 | 예상 기간 |
|------|------|------|-----------|
| Phase 1 | MVP 정적 배포 | 핵심 콘텐츠 완성 + 첫 배포 | 2~3주 |
| Phase 2 | 시각 완성도 향상 | UI 품질 및 인터랙션 개선 | 1~2주 |
| Phase 3 | 챗봇 고도화 | 로컬 LLM 기반 챗봇 구현 및 안정화 | 2~3주 |
| Phase 4 | 배포 안정화 | 성능 최적화, 운영 안정성 확보, 추가 기능 | 1~2주 |

---

## Phase 1 — MVP 정적 배포

> **목표:** 방문자가 5분 이내에 "홍진호가 어떤 게임 개발자인지"를 파악할 수 있어야 한다.  
> 정적 콘텐츠 중심으로 배포 안정성을 먼저 확보한다.

### 작업 목록 (권장 PR 순서)

| 순서 | PR 제목 | 작업 내용 | 선행 조건 | 병렬 가능 |
|------|---------|----------|-----------|-----------|

```
PR1 (초기 셋업)
```

## 후속 티켓/PR 생성 가이드

이 로드맵의 각 행은 독립 PR로 전환 가능하다.  
Jira 티켓 생성 시 아래 필드를 그대로 매핑한다:

| 로드맵 컬럼 | Jira 필드 |
|------------|-----------|
| PR 제목 | Summary |
| 작업 내용 | Description |
| 선행 조건 | Linked Issues (Blocks / Blocked by) |
| 병렬 가능 | 동일 Sprint 배치 여부 |
