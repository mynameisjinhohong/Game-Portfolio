# 로컬 LLM 수동 설치 요구사항

> 이 문서는 맥미니에서 사람이 직접 수행해야 하는 로컬 LLM 설치 작업을 정리한다.  
> 이후 자동화(AI) 작업은 이 문서에 기술된 전제 조건이 모두 완료되었다고 가정하고 진행된다.

---

## 역할 구분

| 구분 | 작업 주체 | 예시 |
|------|----------|------|
| 수동 설치 | **사람 (개발자)** | 런타임 설치, 모델 다운로드, 시스템 권한 허용 |
| 설정·통합 | AI (자동화) | API 엔드포인트 연결, 환경변수 설정 코드, 프론트엔드 연동 |

AI는 파일시스템에 접근하거나 바이너리를 직접 설치할 수 없으므로, 아래 단계는 반드시 개발자가 직접 수행해야 한다.

---

## 1. 런타임 후보 선택

맥미니(Apple Silicon) 환경에서 권장하는 로컬 LLM 런타임은 다음과 같다.

| 런타임 | 특징 | Apple Silicon 지원 |
|--------|------|-------------------|
| **Ollama** (권장) | 설치 간단, REST API 기본 제공, 모델 관리 편리 | ✅ Metal GPU 가속 |
| LM Studio | GUI 제공, 초보자 친화적 | ✅ |
| llama.cpp | 저수준 제어 가능, 설정 복잡 | ✅ |

> **권장**: Ollama — CLI 기반으로 자동화 연동이 가장 용이하고 REST API가 기본 포함된다.

---

## 2. Ollama 설치 (권장 경로)

### 2-1. 설치

```bash
# Homebrew 사용 (권장)
brew install ollama

# 또는 공식 설치 스크립트
curl -fsSL https://ollama.com/install.sh | sh
```

### 2-2. 서비스 실행

```bash
# 백그라운드 서비스로 등록 (맥 재시작 후에도 자동 실행)
brew services start ollama

# 또는 포그라운드 실행 (테스트용)
ollama serve
```

### 2-3. 설치 확인

```bash
ollama --version
# 예: ollama version 0.x.x
```

## 3. 모델 다운로드

챗봇에 사용할 모델을 선택하여 다운로드한다.

### 권장 모델 (포트폴리오 챗봇 용도)

| 모델 | 크기 | 특징 | 다운로드 명령 |
|------|------|------|--------------|
| **llama3.2:3b** | ~2GB | 경량·빠른 응답, 맥미니 8GB RAM에 적합 | `ollama pull llama3.2:3b` |
| llama3.1:8b | ~5GB | 더 나은 품질, RAM 16GB 이상 권장 | `ollama pull llama3.1:8b` |
| gemma2:2b | ~1.6GB | 최경량, 응답 품질 낮음 | `ollama pull gemma2:2b` |

```bash
# 권장 모델 다운로드
ollama pull llama3.2:3b

# 다운로드된 모델 목록 확인
ollama list
```

### ⚠️ llama3.2:3b 한국어 혼용 출력 문제

**현상**: `llama3.2:3b`에 한국어로 질문하면 응답에 영어·중국어 등 다른 언어가 섞여 출력되는 경우가 있다.

**원인**: `llama3.2:3b`는 경량 모델로 다국어 지시 준수 능력이 약하다. 한국어 프롬프트를 받아도 학습 가중치 상 영어 토큰을 우선 생성하는 경향이 있다.

**해결 방법 (시스템 프롬프트 강제)**

백엔드 API에서 Ollama를 호출할 때 `system` 필드에 한국어 전용 지시를 명시한다. 이는 AI(자동화)가 구현할 영역이며, 아래 예시를 참고한다.

```json
{
  "model": "llama3.2:3b",
  "system": "당신은 홍진호의 포트폴리오 챗봇입니다. 반드시 한국어로만 답변하십시오. 어떤 경우에도 영어, 중국어, 일본어 등 다른 언어를 섞지 마십시오.",
  "prompt": "홍진호는 어떤 개발자인가요?",
  "stream": false
}
```

시스템 프롬프트만으로 완전히 해소되지 않으면 다음 대안을 검토한다.

| 대안 | 내용 |
|------|------|
| 모델 업그레이드 | `llama3.1:8b` 또는 `gemma2:9b`로 교체 (RAM 16GB 이상 권장) |
| 응답 후처리 | 서버 측에서 비한국어 문자 비율을 감지해 재시도 로직 추가 |
| Modelfile 커스터마이징 | Ollama `Modelfile`에 `SYSTEM` 지시어를 고정해 모델 자체에 내장 |

**Modelfile 예시** (시스템 프롬프트를 모델에 내장하는 방법):

```dockerfile
FROM llama3.2:3b
SYSTEM """
당신은 홍진호의 포트폴리오 챗봇입니다.
항상 한국어로만 답변하십시오.
영어·중국어·일본어 등 다른 언어는 절대 사용하지 마십시오.
"""
```

```bash
# Modelfile 저장 후 커스텀 모델 생성
ollama create jihno-chatbot -f ./Modelfile

# 생성 확인
ollama list
# jihno-chatbot 항목이 보이면 성공

# 테스트
ollama run jihno-chatbot "안녕하세요, 홍진호는 어떤 개발자인가요?"
```

Modelfile로 생성한 `jihno-chatbot` 모델 ID를 이후 자동화 작업에 전달한다.

## 4. 서버 동작 확인

### 4-1. 포트 확인

Ollama는 기본적으로 `11434` 포트를 사용한다.

```bash
# 포트 리슨 여부 확인
lsof -i :11434

# 또는
curl http://localhost:11434
# 응답: "Ollama is running"
```

### 4-2. 모델 응답 테스트

```bash
# CLI 테스트
ollama run llama3.2:3b "안녕하세요, 자기소개 부탁드립니다."

# REST API 테스트
curl http://localhost:11434/api/generate \
  -d '{"model":"llama3.2:3b","prompt":"안녕하세요","stream":false}'
```

## 5. 보안 및 권한 주의사항

- **로컬 전용 노출**: Ollama는 기본적으로 `localhost`에서만 수신한다. 외부 IP에 노출하지 않도록 주의한다.
- **방화벽**: macOS 방화벽이 활성화된 경우, Ollama가 로컬 루프백만 사용하는지 확인한다.
- **CORS**: 프론트엔드에서 직접 Ollama API를 호출할 경우 CORS 이슈가 발생할 수 있다. 이는 백엔드 프록시를 통해 해결한다(AI가 구현).
- **모델 저장 위치**: 모델 파일은 `~/.ollama/models/`에 저장되며 용량이 수 GB이다. 디스크 여유 공간을 확인한다.
- **macOS Gatekeeper**: 처음 실행 시 "확인되지 않은 개발자" 경고가 뜰 수 있다. 시스템 설정 > 개인 정보 보호 및 보안에서 허용한다.

## 6. AI가 대신할 수 없는 단계 요약

아래 항목은 시스템 수준 작업이므로 **반드시 개발자가 직접 수행**해야 한다.

- [ ] Ollama 바이너리 설치 (`brew install ollama`)
- [ ] `ollama serve` 또는 `brew services start ollama` 실행
- [ ] 모델 다운로드 (`ollama pull llama3.2:3b`)
- [ ] 포트 11434 리슨 확인 (`curl http://localhost:11434`)
- [ ] macOS 보안 팝업 허용 (최초 실행 시)

## 7. 설치 완료 후 개발자가 공유해야 할 정보

설치를 마친 후, 아래 값을 이후 자동화 작업(AI)에 전달한다.

| 항목 | 예시 값 | 비고 |
|------|---------|------|
| Ollama 엔드포인트 | `http://localhost:11434` | 기본값이면 그대로 |
| 사용 모델 ID | `llama3.2:3b` 또는 `jihno-chatbot` | `ollama list`로 확인; Modelfile로 생성한 경우 커스텀 ID 전달 |
| 서비스 실행 방식 | `brew services` / 수동 | 재시작 후 자동 실행 여부 |

| 추가 커스텀 포트 (있다면) | 예: `11435` | 기본 포트 변경 시 |
| 한국어 혼용 해결 방식 | 시스템 프롬프트 / Modelfile / 모델 교체 | 3. 모델 다운로드 섹션의 ⚠️ 항목 참고 |

## 8. 이후 자동화 작업이 의존하는 전제 조건

다음 PR(자동화)은 아래 조건이 모두 충족되었다고 가정하고 진행된다.

1. `http://localhost:11434`에서 Ollama REST API가 응답한다.
2. `ollama list`에 사용할 모델이 존재한다.
3. 맥미니가 로컬 네트워크에서 접근 가능하거나, 개발 서버와 동일 머신에서 실행 중이다.
4. 포트 11434에 대한 방화벽 차단이 없다(로컬 루프백 기준).

이 조건이 충족되지 않으면 백엔드 API 연동 및 챗봇 프론트엔드 구현 PR이 정상 동작하지 않는다.
