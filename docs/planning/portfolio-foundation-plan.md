# 포트폴리오 공통 요구사항 및 성공 기준

## 1. 프로젝트 목표

홍진호의 게임 개발 역량과 작업물을 면접관·인사담당자에게 효과적으로 전달하는 포트폴리오 사이트를 제작하고, 실제 배포 가능한 수준까지 완성한다.

### 목표 달성 지표

| 지표 | 기준 |
|------|------|
| 첫 화면 인상 전달 시간 | 방문 후 10초 이내에 홍진호가 게임 개발자임을 파악 가능 |
| 핵심 프로젝트 접근성 | 스크롤 없이 또는 1회 스크롤 이내에 대표 게임 확인 가능 |
| 챗봇 실용성 | 질문에 대해 홍진호의 실제 경험을 기반으로 답변 가능 |
| 배포 안정성 | 외부 사용자가 오류 없이 사이트 탐색 완료 가능 |

---

## 2. 핵심 사용자 관점

### 면접관 / 인사담당자

- **목적**: 후보자의 기술 수준과 프로젝트 경험을 빠르게 검토
- **행동 패턴**: 5~10분 이내 훑어보기, 관심 있는 항목만 깊이 탐색
- **필요한 것**: 명확한 역할, 사용 기술, 결과물 링크
- **피해야 할 것**: 장황한 설명, 느린 로딩, 깨진 링크

### 처음 방문하는 실무자

- **목적**: 홍진호가 어떤 개발자인지 파악, 챗봇을 통해 궁금한 점 질문
- **행동 패턴**: 흥미로운 요소에 이끌려 탐색, 챗봇과 대화
- **필요한 것**: 직관적인 내비게이션, 반응 빠른 챗봇, 게임 데모 접근성

---

## 3. 전달해야 할 핵심 인상

1. **"게임을 직접 만든 개발자"** — 실제 플레이 가능한 결과물이 먼저 보여야 한다
2. **"기술적으로 탄탄하다"** — 각 프로젝트에서 사용한 기술과 이유가 명시되어야 한다
3. **"함께 일하고 싶다"** — 챗봇 대화를 통해 홍진호의 성향과 역량이 자연스럽게 전달되어야 한다

---

## 4. 공통 UX 원칙

### 4.1 결과물 우선

- 텍스트 설명보다 게임 스크린샷, 플레이 영상, Itch.io 링크가 먼저 보여야 한다
- 각 게임 카드는 한눈에 역할(게임 장르, 사용 엔진, 담당 파트)을 파악할 수 있어야 한다

### 4.2 빠른 이해

- 페이지당 전달하는 핵심 메시지는 하나로 유지한다
- 불필요한 애니메이션이나 인터랙션은 추가하지 않는다
- 내비게이션은 최대 2단계(메인 → 상세)로 제한한다

### 4.3 챗봇 실용성

- 챗봇은 홍진호의 실제 데이터(프로젝트, 기술 스택, 경험)를 참조해 답변한다
- 모르는 질문에는 솔직하게 응답하며 관련 프로젝트 링크로 안내한다
- 응답 속도가 사용 경험에 영향을 주므로, 로컬 LLM 레이턴시를 고려해 UI 피드백을 제공한다

### 4.4 일관된 시각 언어

- 색상, 폰트, 카드 레이아웃은 사이트 전체에서 일관되게 사용한다
- 다크/라이트 모드 중 하나를 선택해 통일한다 (초기 결정 후 변경 최소화)

---

## 5. 배포 품질 기준

| 항목 | 기준 |
|------|------|
| 페이지 로드 속도 | LCP 2.5초 이내 (모바일 기준) |
| 반응형 지원 | 모바일(375px), 태블릿(768px), 데스크톱(1280px) 레이아웃 지원 |
| 접근성 | 주요 인터랙티브 요소에 키보드 접근 가능 |
| 링크 유효성 | 배포 전 모든 외부 링크(Itch.io 등) 동작 확인 |
| 챗봇 가용성 | 로컬 LLM 서버 다운 시 적절한 오류 메시지 표시 |
| 브라우저 호환 | Chrome, Safari, Firefox 최신 버전 지원 |

---

## 6. 이번 범위 (In Scope)

- 게임 소개 페이지 (게임 목록, 각 게임 상세 카드)
- 홍진호 소개 챗봇 (로컬 LLM 기반, 포트폴리오 문맥 참조)
- 공통 레이아웃 및 내비게이션
- 정적 사이트 배포 파이프라인

---

## 7. 이번 범위 제외 (Out of Scope)

- 블로그 또는 기술 글 섹션
- 사용자 로그인 / 인증 기능
- 관리자 대시보드 또는 콘텐츠 관리 시스템(CMS)
- 다국어(한국어 외) 지원
- 게임 내 플레이 임베드 (Itch.io 링크 이동으로 대체)
- 실시간 협업 또는 소셜 기능
- SEO 고도화 (기본 메타태그 외 추가 최적화 제외)

---

## 8. 작업 우선순위

1. **게임 소개 페이지** — 핵심 결과물 전달, 가장 먼저 완성
2. **챗봇 연동** — 포트폴리오 탐색 경험 개선의 핵심
3. **공통 UX 다듬기** — 전체 일관성 확보
4. **배포 및 품질 검증** — 실제 사용자 환경 기준 최종 점검
