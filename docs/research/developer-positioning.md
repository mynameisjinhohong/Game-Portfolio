# 홍진호 개발자 강점 및 포지셔닝 요약

**작성일:** 2026-05-18  
**목적:** 포트폴리오 문안 및 챗봇 컨텍스트 작성을 위한 핵심 포지셔닝 정리  
**참조 자료:** archive/brainstorming/portfolio-analysis-frame.md, docs/planning/portfolio-foundation-plan.md, workspace/docs/concept-analysis.md

---

## 핵심 포지셔닝 문장

> **"아이디어를 직접 플레이 가능한 게임으로 완성하고, AI 챗봇으로 자신을 소개하는 실행형 게임 개발자"**

이 문장은 두 가지 차별점을 동시에 전달한다.  
첫째, 단순 기획·습작이 아닌 **Itch.io 배포까지 완료**한 실제 완성 경험.  
둘째, 포트폴리오 사이트 자체에 **AI 챗봇을 직접 구현**해 기술 응용력을 증명.

---

## 어필 포인트 (5개)

### 1. 완성까지 가는 실행력

- **메시지**: 만든 게임이 플레이 가능한 상태로 외부에 배포되어 있다.
- **면접관 관점**: 포트폴리오에 "제작 중" 이 아닌 실제 링크(Itch.io)가 걸려 있다는 것은 기획부터 빌드·배포 전 과정을 혼자 또는 팀 내에서 끝까지 처리한 증거다.
- **연결 자료**: portfolio-analysis-frame.md §1 (차별점 항목), portfolio-foundation-plan.md §3 "게임을 직접 만든 개발자"
- **포트폴리오 문안 예시**: "지금까지 만든 게임은 모두 Itch.io에 배포되어 있어 바로 플레이해볼 수 있습니다."

---

### 2. AI·LLM 응용 구현 경험

- **메시지**: 챗봇을 장식으로 붙인 것이 아니라, 맥미니 로컬 LLM 위에 포트폴리오 문맥을 직접 주입해 동작시킨다.
- **면접관 관점**: 사이드 프로젝트로 LLM을 실제 프로덕트에 연결한 경험은 "트렌드를 실험하는 개발자"가 아니라 "도구를 목적에 맞게 쓸 수 있는 개발자"라는 신호다.
- **연결 자료**: portfolio-analysis-frame.md §1 (정체성: AI 도구를 직접 구현하는 엔지니어), chatbot-implementation-plan.md
- **포트폴리오 문안 예시**: "로컬 LLM을 직접 구성해 포트폴리오 탐색 챗봇을 구현했습니다. 질문하시면 제 경험과 프로젝트를 바탕으로 답변합니다."

---

### 3. 사용자 관점 중심 개발

- **메시지**: 게임이든 포트폴리오든 "방문자·플레이어가 무엇을 먼저 보게 되는가"를 기준으로 구성한다.
- **면접관 관점**: 기술 열거보다 결과물이 먼저 보이도록 배치하는 판단은 UX 감각과 커뮤니케이션 능력을 동시에 드러낸다.
- **연결 자료**: portfolio-foundation-plan.md §4.1 "결과물 우선", portfolio-analysis-frame.md §2 (첫 5초~3분 설계)
- **포트폴리오 문안 예시**: "설명보다 결과물이 먼저 눈에 들어오도록 사이트를 구성했습니다."

---

### 4. 자기주도 학습과 완성 이력

- **메시지**: 독립적으로 게임 개발 기술을 습득하고 다수의 프로젝트를 완료했다.
- **면접관 관점**: 혼자 Unity 학습 → 게임 완성 → 배포까지 반복한 이력은 명시적 지도 없이도 새 기술을 습득·적용하는 자기주도성을 보여준다.
- **연결 자료**: portfolio-analysis-frame.md §1 강점 키워드 (자기주도, 완성도), §3-1 면접관 관점
- **포트폴리오 문안 예시**: "새로운 기술을 배울 때 튜토리얼에서 멈추지 않고 직접 만들어 배포하는 것을 목표로 합니다."

---

### 5. 기술과 감성의 연결

- **메시지**: 기술 스택 선택이 게임의 장르·분위기·플레이어 경험에 맞춰 이루어진다.
- **면접관 관점**: "왜 이 엔진·이 구조를 선택했는가"에 대한 답이 있다는 것은 도구를 수단으로 쓰는 성숙도를 나타낸다.
- **연결 자료**: tech-stack.md, portfolio-analysis-frame.md §4 기준3 "구현 대비 임팩트"
- **포트폴리오 문안 예시**: "각 게임마다 기술 선택의 이유와 배운 점을 카드에 직접 기재했습니다."

---

## 면접관 관점에서 기억할 강점과 차별점

| 항목 | 내용 |
|------|------|
| **기억에 남는 강점** | Itch.io에 실제 배포된 완성 게임이 있다 |
| **기억에 남는 강점** | 포트폴리오 사이트 자체가 AI 챗봇 구현물이다 |
| **기억에 남는 강점** | 결과물이 텍스트 설명 전에 눈에 들어오도록 설계했다 |
| **차별점 (희소성)** | 게임 완성 + AI 챗봇 직접 구현을 동시에 보여주는 포트폴리오는 드물다 |
| **차별점 (신뢰성)** | 로컬 LLM을 직접 구성한 경험은 클라우드 API 호출과 다른 기술 이해를 전제한다 |
| **주의 사항** | 완성된 게임 수가 많지 않을 경우 "다양한 기술 폭"보다 "깊은 완성 경험"으로 포지셔닝해야 한다 |

## 포지셔닝 적용 가이드

### 히어로 섹션
- 핵심 포지셔닝 문장 변형 활용
- "직접 만든 게임과 대화형 AI로 포트폴리오를 탐색할 수 있습니다" 수준의 부제

### 게임 갤러리 섹션
- 어필 포인트 1 (실행력) + 어필 포인트 5 (기술·감성 연결) 적용
- 각 카드에 플레이 링크, 사용 기술, 배운 점 명시

### 기술 스택 섹션
- 어필 포인트 2 (AI 응용) + 어필 포인트 4 (자기주도) 적용
- 단순 목록보다 "왜 이 기술인가"를 한 줄씩 병기

### 챗봇 인터페이스
- 어필 포인트 3 (사용자 관점) 전면 적용
- 챗봇이 포트폴리오 탐색의 시작점이 되도록 첫 인사말 설계
